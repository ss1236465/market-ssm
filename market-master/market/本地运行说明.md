# 本地运行

本机运行环境已配置完成，使用 Java 8、Tomcat 9 和独立的 MySQL 测试实例。

## 打开项目

双击本目录中的 `启动项目.cmd`。脚本会编译项目、启动数据库和网站，并打开浏览器。

访问地址：http://127.0.0.1:8080/chaoshi/

管理员入口：选择“管理员入口”，账号 `15203111`，密码 `1234`。

普通员工入口：选择“普通员工入口”，账号 `15203122`，密码 `123456`。

这些账号来自项目自带的示例 SQL 数据。

## 停止与再次启动

双击 `停止项目.cmd` 正常停止本项目的网站和数据库。数据会保留，再次启动不会重复导入 SQL。

关闭浏览器或 VS Code 不会停止后台服务。

也可以在本目录终端执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\run-local.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\stop-local.ps1
```

## 本机配置

- 网站只监听本机 `127.0.0.1:8080`。
- 项目数据库监听 `127.0.0.1:3307`，数据目录为 `.local/mysql-data`。
- 数据库使用随机生成的本地密码，配置位于 `.local`，该目录已加入 Git 忽略规则。
- 启动脚本把 `.local/db.properties` 复制到构建目录，以使用独立的测试数据库。
- Java 和 Tomcat 位于 `.local/tools`，Maven 使用本机 IntelliJ IDEA 自带的版本。
- Maven 下载代理配置位于 `.local/maven-settings.xml`；首次构建已缓存所需依赖。
- 编译日志：`.local/logs/build.log`。
- 网站日志：`.local/logs/tomcat-stdout.log` 和 `.local/logs/tomcat-stderr.log`。

已修复的启动问题：补充 Java 8/UTF-8 编译配置；将 Java EE API 设为服务器提供；移除不存在的 `DateConverterInitServlet` 配置；将 MySQL 驱动更新为 Connector/J 8.0.33。
